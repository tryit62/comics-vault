COMIC VAULT V2 — iPad / PWA

Cette version est une application web installable (PWA) sans serveur Python.
Elle stocke les comics localement dans IndexedDB et fonctionne hors ligne après la première visite.

IMPORTANT
- Un iPad ne peut pas installer la PWA directement depuis le ZIP.
- Le dossier doit être publié sur un hébergement HTTPS (GitHub Pages, Netlify, Cloudflare Pages, etc.).
- Une fois publié : ouvrir l'adresse dans Safari > Partager > Sur l'écran d'accueil.
- Les données restent locales à l'appareil/navigateur : utilisez régulièrement Réglages > Exporter.
- Cette V2 n'inclut pas encore la synchronisation cloud ni la reconnaissance automatique de code-barres.
