Après le déploiement GitHub Pages :
1. Ouvre l'adresse du site dans Safari et actualise-la.
2. Vérifie que le nouveau logo apparaît lorsque tu choisis Partager > Sur l'écran d'accueil.
3. Supprime ensuite l'ancienne icône de l'écran d'accueil et ajoute de nouveau Comic Vault.

Ne supprime pas les données de Safari : Comic Vault V2 stocke la collection localement dans IndexedDB.
