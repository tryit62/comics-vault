COMIC VAULT V2.2

Base : V2.1 stable, avec le nouveau logo iPad conservé.
La base IndexedDB reste nommée "comic-vault" : aucune migration destructive n'est effectuée.

Nouveautés :
- fiche détaillée avant modification
- regroupement automatique par séries
- section Mes boîtes
- champs Boîte et Position
- recherche avancée : statut, favoris, note minimum, tris
- nouveaux champs Arc narratif et Collection éditoriale
- structure compatible avec les anciennes fiches

Mise à jour GitHub :
Remplace index.html, style.css, app.js et sw.js avec les fichiers V2.2.
Les fichiers d'icônes de V2.1 restent identiques.

PRÉCAUTION :
Avant toute mise à jour, utiliser Réglages > Exporter dans Comic Vault et conserver le JSON de sauvegarde.
