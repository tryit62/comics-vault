COMIC VAULT V4.1 — IPAD

Cette version est conçue pour éviter l'envoi d'un dossier 'covers' sur GitHub depuis l'iPad.

CONTENU
- index.html
- style.css
- app.js
- seed.json
- 108 images JPG placées directement à la racine
- aucun dossier covers
- aucun sw.js

IMPORTANT POUR TON INSTALLATION ACTUELLE
Tu as déjà importé les 54 fiches dans V4. Tu n'as PAS besoin de les réimporter.
V4.1 reconnaît automatiquement les anciens chemins ./covers/xxx.jpg et les redirige vers ./xxx.jpg.

INSTALLATION
1. Sur le repository comics-vault, remplace index.html, style.css, app.js et seed.json.
2. Téléverse toutes les images JPG du ZIP directement à côté de index.html.
3. Ne remets pas sw.js.
4. Attends GitHub Pages puis recharge le site.
5. Les couvertures des 54 comics doivent apparaître.
6. N'appuie PAS à nouveau sur « Importer mes 54 comics préparés ».

NOUVEAUX COMICS
Les nouvelles couvertures ne vont PAS sur GitHub.
Quand tu ajoutes une couverture dans Comic Vault, elle est redimensionnée avant stockage dans la base locale comic-vault-v4.

SAUVEGARDE
Réglages > Exporter la sauvegarde complète
Cette sauvegarde inclut désormais fiches + couvertures.
Réglages > Restaurer une sauvegarde permet de remettre fiches + couvertures dans la base V4.

CONSERVE encore le JSON Recovery original jusqu'à validation complète.
